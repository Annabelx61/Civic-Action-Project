# Civic Action Use Cases

1. Students need my projects to be easily accessible. When they log in, all of the projects they're involved in should be the first thing they see.

2. Students need to be able to update projects convieniently. When students veiw the page of one of their projects, they should have buttons that allow them to easily enter more hours, add pictures, or add descriptive information.

3. Admin need to be able to view student's projects, see the updates they've been making, and approve all updates that haven't yet been approved all in one click of a button.

4. Admin need to be able to approve all students in a workshop with the same click of a button. They should NOT have to go through and approve all participating students individually.

5. Admin probably want to be able to see a list of all of their students.

6. It should be made obvious to admin when projects have been updated and are awaiting approval.
